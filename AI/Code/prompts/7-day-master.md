# 7-Day Build Prompts

Use one prompt per day. At the end of each day, run tests and commit your work.

1. Foundation — FastAPI skeleton and environment.
2. Security — Bandit local scanning.
3. AI — Gemini/Groq structured review.
4. API — validation, schemas, tests.
5. Dashboard — local UI.
6. Quality — tests and hardening.
7. Portfolio — README, demo, release polish.

Each daily prompt is intentionally scoped so the project grows incrementally rather than generating an unmaintainable monolith.
